# Applogger

> The first educational macOS Keylogger

Applogger is a a applescript programmed applcation designed to track what time you are using certain applications, this can help with screentime control, parental settings, and information.

---

## Built With

- Apple script the .scpt file()
- Uses TXT files for data.
